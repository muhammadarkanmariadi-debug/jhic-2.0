# PHASE.md — How Our Website Is Being Built (Simple Version)

> Short note: our website is currently a **prototype** — a "first draft" that shows
> how everything will look and work, using sample information. These are the stages
> we go through to turn it into the real, finished website.

---

## Stage 0 — First draft (we are here now)
- We designed the look and sections of every page (home, school info, programs,
  news, alumni, facilities, contact, admission pages).
- Buttons, colours, headings, and boxes already look the same across the site.
- Some parts of the site can already be edited by staff (general program content
  and the school schedule), but the rest still uses example/placeholder information.

## Stage 1 — Making everything look the same
- Give every page a consistent look and feel: same colours, fonts, boxes, and buttons.
- Build simple building blocks that reappear across the site, so later changes are easy.

## Stage 2 — Building the "engine" behind the site
- Create a secure storage place that will hold all the school's information.
- Set up the sign-in system so each staff member only edits their own part.

## Stage 3 — Letting staff update content easily
- Build simple editing screens where school staff can add or change:
  - School programs and specialisations
  - News and announcements
  - Job / scholarship / competition info
  - Teachers, facilities, extracurriculars, achievements, testimonials
  - FAQs, contact services, organization chart
  - Food and housing costs, school products, trial class, interest quiz
  - School schedule, general info
- Goal: staff can keep the website fresh without needing a developer.

## Stage 4 — Showing the latest information on the site
- Connect every page to the content staff set, so visitors always see the current
  information (instead of example text).
- Each page pulls the real, up-to-date data from the editing system.

## Stage 5 — Adding features that respond to visitors
- Chat assistant on every page to answer questions.
- Feedback / survey form for visitors.
- Career-interest quiz ("which programme is right for me").
- Check graduation status by student number.
- Step-by-step admission (PPDB/SPMB) timeline.

## Stage 6 — Checking and polishing before launch
- Test everything carefully (emails, phone, different screens/devices).
- Make pages load quickly and work well for everyone.
- Review spelling, structure, and content one last time.
- Then go live for the public.
